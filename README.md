# SPEED CENTER V2 - Precision Ops

Sistema completo de gestión para taller automotriz, optimizado para ser alojado en **GitHub Pages** e integrado con **Supabase**.

## Estructura de Archivos
- `index.html`: Aplicación y modales del sistema Stitch v12.
- `css/styles.css`: Estilos visuales del sistema de diseño Precision Ops.
- `js/supabase.js`: Manejo de conexión a la base de datos Supabase.
- `js/migration.js`: Script de migración y vinculación V1 → V2.
- `js/app.js`: Lógica interactiva del tablero y KPIs.

## Pasos de Despliegue en GitHub Pages
1. Descomprime este archivo ZIP.
2. Sube todos los archivos a la raíz de tu repositorio de GitHub.
3. Ve a **Settings > Pages** en GitHub y activa la rama `main` como origen.
